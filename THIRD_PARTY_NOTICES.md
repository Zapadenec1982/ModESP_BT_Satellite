# Third-party code in the satellite image

What is linked into `modesp_bt_satellite.bin`, where it comes from and the licence
**as found in the files** on 2026-09-21. This is an inventory of facts for whoever
has to decide what they mean; it is not legal advice and draws no conclusion.

| Body of code | Where in this tree | Licence as found in the files | Notes |
|---|---|---|---|
| ESP-IDF v5.5.5 (`b774170ff46c393eeb5e495ea37936038d3f4f4f`) | shared checkout named by `idf.pin`; not in this repository | `LICENSE` at the IDF root: Apache-2.0. Components inside the IDF carry their own notices (FreeRTOS kernel, newlib, mbedTLS and others); the IDF tree is authoritative for those | Everything below `components/bt` is copied out of it by `tools/setup.ps1` / `tools/setup.sh` |

(The license text refers to this as 'Object' form.)" | Binary only. Below the VHCI boundary; the patches do not touch it |
| Bluedroid host stack | copied into `components/bt/host/bluedroid/`, then `patches/0001`..`0011` applied | File headers: "Copyright (C) 2004-2012 Broadcom Corporation", "Copyright (C) 2014 Google, Inc.", Apache-2.0 | The patch series is this project's; its content is a delta derived from `WillyBilly06/ESP32-A2DP-SINK-WITH-CODECS-UPDATED` (`docs/BASE.md`) |

| Helix fixed-point AAC decoder (RealNetworks, 2005) | `bt_overlay/host/bluedroid/external/libaac-lc/libhelix_aac/` | Every source file: "Portions Copyright (c) 1995-2005 RealNetworks, Inc. ... subject to the current version of the RealNetworks Public Source License (the 'RPSL') ... unless you have licensed the file under the current version of the RealNetworks Community Source License (the 'RCSL')", with URLs at helixcommunity.org. **No licence text file is shipped in the tree**; `readme.txt` is a technical overview and says nothing about terms | Built when `CONFIG_BT_A2DP_AAC_DECODER=y` (the default in `sdkconfig.defaults`). The wrapper `libaac-lc/aac_decoder_helix.c` carries no notice. **Locally modified** on 2026-10-12 (commits `19c6b74`, `2808367`): `noiseless.c`, `decelmnt.c`, `bitstream.c` and `coder.h` gained bounds checks that reject malformed frames (`max_sfb`, section lengths, pulse positions, negative bit counts, TNS order, CPE M/S mask end), and the gain-control parser in `noiseless.c` was removed in favour of rejecting the frame. The licence header itself states no requirement to mark changes (its "Contributor(s):" field is empty, and it refers to the RPSL/RCSL, whose text is not in the tree); each modified file nevertheless carries a dated change note in its description comment below the licence block, which is left untouched |
